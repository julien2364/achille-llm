# Sécurité

Les scripts téléchargent des exécutables tiers et des modèles : examinez-les et vérifiez les licences et l’espace disque avant exécution. Les versions et empreintes épinglées limitent les modifications inattendues ; elles ne garantissent pas l’absence de vulnérabilités.

Pour signaler une vulnérabilité du code de ce dépôt : julien.daures@gmail.com, objet « Sécurité Achille LLM ». Ne publiez pas de secret ni de donnée personnelle dans une issue. Aucun délai de réponse garanti. Les problèmes d’Ollama, llama.cpp et des modèles tiers doivent être signalés à leurs mainteneurs.

Aucun service exposé, poids de modèle, clé API ou donnée de production n’est livré ici.
